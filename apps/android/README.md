# Android 운영 앱

Kotlin/Compose/Room 단일 모듈입니다. `local.properties.example`을 `local.properties`로 복사하고 `sdk.dir`에 로컬 Android SDK 경로를 입력한 뒤 `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`로 검증합니다. JDK 17, Android SDK 36, Gradle 9.4.1을 사용합니다. 실제 키가 들어간 `local.properties`, DB, APK, 서명키는 Git에서 제외합니다.

앱의 첫 실행은 빈 데이터입니다. 회원·행사·회비 원장·할 일·연락 초안·템플릿·연락 이력은 이 기기의 Room에 저장합니다. 설정의 화면 테마와 학기는 DataStore에 저장합니다. 앱 백업은 비활성화되어 있으며 현재 사용자 파일 백업·복구 화면은 구현되지 않았습니다. 앱을 삭제하면 로컬 데이터를 잃을 수 있으므로 실명단 투입 전 백업 기능을 완성해야 합니다.

문자는 대상별 `ACTION_SENDTO`로 기본 문자 앱 작성 화면을 엽니다. 연락 기록의 `앱 전달됨`과 `사용자 발송 확인`은 실제 통신사 전송 결과가 아닙니다. Kakao 공유는 `local.properties`에 `kakao.nativeAppKey`와 등록된 `kakao.shareUrl`을 넣었을 때 공식 SDK 텍스트 공유를 시도합니다. 설정이 없거나 사용할 수 없으면 공통 문구를 Android 일반 공유로 넘깁니다. 공통 공유는 개인 이름·금액·번호·개인 토큰을 검사하며, 수신자를 대신 선택하거나 실제 발송으로 기록하지 않습니다.

알림은 WorkManager가 운영자에게 연락 확인을 상기시킵니다. 정확한 시각은 보장하지 않고 자동 문자를 보내지 않습니다. Android 13 이상에서 알림 권한이 거부되면 앱의 연락 알림 목록에 거부 상태를 보존합니다.

설정에 서버 HTTPS 주소와 운영자 토큰을 넣으면 행사 화면에서 수동 게시, 공통·개인 링크 발급, 서버 응답 가져오기를 수행합니다. 디버그 에뮬레이터만 `http://10.0.2.2`를 허용합니다. 행사 일시와 마감은 게시할 때 시간대가 포함된 ISO 8601 형식이 필요합니다. 행사 취소 상태도 Room에 저장해 다음 게시 요청에 포함하며, 기존 응답은 보존합니다. 게시·링크 요청은 작업 ID를 먼저 Room에 저장한 뒤 같은 본문으로 재시도합니다. 링크는 서버 성공 응답 후에만 표시하고 30일 만료를 표시합니다. 서버 응답과 입금 확인 요청은 읽기 전용이며 회비 원장에 자동 반영하지 않습니다. 게시 전 수동 참석 응답의 최초 이관과 게시 후 운영자 응답 수정·충돌 검토는 아직 연결되지 않아, 수동 응답이 있는 행사는 게시를 막고 게시 중·게시 후에는 로컬 수동 응답 수정을 막습니다. 자동 동기화는 없고 마지막 가져오기 시각이 보입니다.

서버 설정과 운영자 토큰은 앱 전용 DataStore에 보관하며 OS 백업에서 제외합니다. 게시나 링크 요청이 저장된 뒤에는 그 데이터가 다른 서버를 가리키지 않도록 서버 주소 변경을 막고 토큰 교체만 허용합니다. 서버가 확정적으로 거부한 게시 요청은 입력을 고쳐 새 작업 ID로 시도할 수 있으며, 네트워크 오류나 서버 5xx 뒤에는 같은 작업 ID와 본문을 유지합니다. 현재 별도 앱 잠금과 사용자 파일 백업·복구가 없으므로 실제 운영 토큰·실명단 투입 전 단말 보호와 백업 흐름을 완성해야 합니다. 실제 SKT 단말의 회선 선택, 문자 장문, 취소 후 복귀, 카카오톡 공유, 재시작 영속성 및 다른 기기의 공개 웹 접근은 별도 확인이 필요합니다.

공통 공유 문구에 `/respond#` 링크가 있으면 현재는 개인 토큰과 공통 토큰을 화면만으로 구별할 수 없어 공유를 막습니다. 서버와 범위를 확인하는 연결을 추가하기 전에는 공통 링크를 행사 화면에서 개별 복사해 사용해 주세요.

CI 디버그 APK는 개발 검증용입니다. 매 실행의 디버그 서명 동일성은 보장하지 않으므로 업데이트 설치가 거절되면 데이터가 있는 앱을 삭제하지 말고 안정된 비공개 서명과 백업 경로를 먼저 준비하세요. 최신 단위/lint/APK 성공 및 기기 미검증 조건은 ../../docs/STATUS.md에 기록합니다.
