# Android 운영 앱

Kotlin/Compose/Room 단일 모듈입니다. `local.properties.example`을 `local.properties`로 복사하고 `sdk.dir`에 로컬 Android SDK 경로를 입력한 뒤 `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`로 검증합니다. JDK 17, Android SDK 36, Gradle 9.4.1을 사용합니다. 실제 키가 들어간 `local.properties`, DB, APK, 서명키는 Git에서 제외합니다.

앱의 첫 실행은 빈 데이터입니다. 회원·행사·회비 원장·할 일·연락 초안·템플릿·운영 도구는 Room v4에 저장하며 명시적 1→2→3→4 migration으로 기존 자료를 보존합니다. 설정은 공통 DataStore를 사용합니다. OS 자동 백업은 비활성이고, 설정의 사용자 파일 백업·복원은 AES-GCM으로 암호화된 `.comsbak`을 SAF로 저장합니다. 복원 전 내용을 검토하고 기존 자료의 별도 암호화 복구 파일부터 저장합니다. 인증 토큰은 백업하지 않고 같은 서버 재연결을 요구합니다. 선택형 앱 잠금은 OS 화면 잠금 인증을 사용하며 잠금 중 개인정보 화면과 대화상자를 제거합니다. 앱 삭제 전 사용자 백업을 보관하고, 암호를 잊으면 복원할 수 없음을 확인하세요.

문자는 대상별 `ACTION_SENDTO`로 기본 문자 앱 작성 화면을 엽니다. 연락 기록의 `앱 전달됨`과 `사용자 발송 확인`은 실제 통신사 전송 결과가 아닙니다. Kakao 공유는 `local.properties`에 `kakao.nativeAppKey`와 등록된 `kakao.shareUrl`을 넣었을 때 공식 SDK 텍스트 공유를 시도합니다. 설정이 없거나 사용할 수 없으면 공통 문구를 Android 일반 공유로 넘깁니다. 공통 공유는 개인 이름·금액·번호·개인 토큰을 검사하며, 수신자를 대신 선택하거나 실제 발송으로 기록하지 않습니다.

알림은 WorkManager가 운영자에게 연락 확인을 상기시킵니다. 정확한 시각은 보장하지 않고 자동 문자를 보내지 않습니다. Android 13 이상에서 알림 권한이 거부되면 앱의 연락 알림 목록에 거부 상태를 보존합니다.

설정의 HTTPS 주소와 운영자 토큰으로 행사 게시·링크 발급/취소·응답 동기화를 수행합니다. 디버그 에뮬레이터만 `http://10.0.2.2`를 허용합니다. 게시 날짜는 시간대가 포함된 ISO 8601로 입력합니다. 최초 게시에는 실제 수동 응답만 이관하고 출석만 기록한 미응답 행은 로컬에 남깁니다. 응답 제안·회원 연결·반려·초대 취소는 작업 ID와 본문을 영속 대기함에 먼저 기록하고 충돌을 검토합니다. 변경 커서와 스냅샷은 함께 반영하며 연결 조건의 WorkManager 동기화와 수동 재시도를 제공합니다. 오래된 백업에 없는 서버 행사는 설정에서 실제 행사/응답만 검토해 복구하고 회원·원장을 임의 생성하지 않습니다.

입금 요청은 납부 완료가 아닙니다. 실제 확인 금액을 서버에 예약하고 고유 요청/원장 ID로 한 번 반영한 뒤 서버 확정을 전달합니다. 과거 영수증·복원 누락은 같은 owner와 예약 내용을 대조해 복구합니다. 원본 이력은 지우지 않고 정정 원장을 추가합니다.

서버 설정과 운영자 토큰은 앱 전용 DataStore에 보관하며 OS 백업과 사용자 파일 백업에서 인증 정보를 제외합니다. 온라인 기록이 생긴 뒤 다른 서버로 바꾸지 않으며 복원 후에도 저장된 origin을 확인합니다. 확정적으로 거절된 게시 요청은 수정할 수 있고 불확실 실패는 같은 작업 ID와 본문을 유지합니다. 실제 SKT 단말·회선·장문·복귀, Kakao 등록/실제 공유와 공개 HTTPS 호스트의 별도 기기 접근은 별도 확인 사항입니다.

공통 공유에는 발급이 확인된 유효 HTTPS 공통 링크만 허용합니다. 개인 링크나 취소 대기 링크는 공유·복사하지 않습니다. 연락 알림과 외부 공유 실행은 실제 발송이 아닙니다. DB·사용자 백업·토큰·실제 설정·서명키는 공개 Git에 넣지 않습니다.

CI 디버그 APK는 개발 검증용입니다. 매 실행의 디버그 서명 동일성은 보장하지 않으므로 업데이트 설치가 거절되면 데이터가 있는 앱을 삭제하지 말고 안정된 비공개 서명과 백업 경로를 먼저 준비하세요. 최신 단위/lint/APK 성공 및 기기 미검증 조건은 ../../docs/STATUS.md에 기록합니다.
