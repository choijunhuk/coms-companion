# 구현 순서와 완료 조건

이 문서는 제품 명세의 단계와 현재 코드/검증 경계를 나눠 관리합니다. 완료 상태는 [STATUS.md](STATUS.md)에 최신 증거를 기록합니다. 앱 코드가 있어도 실기 통신·공개 배포·실제 회원 수용이 확인되지 않으면 해당 항목은 외부 검증 대기로 남깁니다.

## P0. 저장소와 기준 문서

완료: 공개 저장소 `https://github.com/choijunhuk/coms-companion`, Android·웹·서버 코드, 가상 데이터만 사용한 개발 문서와 공개 파일 검사가 있습니다. 공개 저장소는 운영 서비스 배포가 아닙니다.

## P1. Android 운영 앱

구현된 코드: 다섯 기본 탭, 회원/CSV 검토, 행사 작성·출석·일정 투표, 회비 부과와 확인·면제·정정 원장, 템플릿 연락 초안, 알림, 선택형 휴대폰 자격 증명 잠금, 암호화 SAF 백업/복구, 운영비·대여·모집·회의 기록을 제공합니다. Room schema 1→2→3→4 migration을 명시합니다. 최초 행사 게시 시 실제 RSVP만 이관하고 `미응답` attendance-only 행은 올리지 않습니다.

외부 수용 조건: 2026-10-14 SM-S928N/Android16에서 삼성 문자 앱의 가상 수신자·한글 본문 전달과 앱 복귀를 확인했습니다. 로컬 Kakao 키·플랫폼·서명 해시·개발 안내 도메인 등록 후 공식 공유 선택 화면도 확인했습니다. 실제 발송·수신, 장문·이모지·듀얼 SIM·요금제와 실기의 보호/복원 검증은 남아 있습니다. 이 앱은 문자를 자동 발송하지 않으며 기본 SMS 권한도 요청하지 않습니다. 공개 설정 예시와 CI에는 Kakao 키가 없으며 일반 공유 대안을 제공합니다.

## P2. 회원 웹 응답과 온라인 동기화

구현된 코드: 회원의 참석 응답·안내 확인·일정 투표·입금 확인 요청, 응답 수정/불확실 저장 복구, 운영자 수동 응답 최초 이관, durable 작업 대기함, 변경 커서, 명시적 충돌 해결, 개인/공통 링크 발급과 행사/회원 범위 취소, 수동/네트워크 조건 동기화를 제공합니다. 회원 탈퇴는 개인 링크와 연결된 공통 응답 수정 권한도 취소합니다. 오래된 백업에만 없는 서버 행사는 운영자 검토 대상으로 보류하고, 행사/응답 스냅샷만 복구하며 검토 전 커서를 이동하지 않습니다. 입금 확인은 서버 예약→Android 원장 반영→서버 확정의 단계로 처리합니다. 회원에게는 입금 요청과 실제 확인 금액을 구별해 표시합니다.

공개 수용: `https://coms.kw.ac.kr/companion/`의 독립된 응답 웹·API와 기존 등록 명부의 인증된 읽기 전용 연결을 배포했습니다. 실제 Chrome의 응답·수정·새로고침, 컨테이너 재생성 뒤 저장 유지와 기존 COMS 캐시 경로 공존을 확인했습니다. 기존 COMS 로그인으로 공통 링크 응답자를 등록 명부 회원에 자동 연결하는 기능도 배포했고, 실제 회원 확인·저장·수정·로그인 복귀와 앱 변경 API의 회원 ID를 확인했습니다. 새 APK 설치·명부 적용·앱 응답 동기화의 실기 검사는 사용자가 기기 연결을 나중에 하기로 하여 남아 있습니다. 서버 백업의 실제 복원·장기 장애 수용도 별도 검증입니다.

## P3. 운영 도구

구현된 코드: 확인된 회비 원장과 연결한 행사 정산, 별도 비용·정정 기록, 물품 대여/반납, 모집 지원자와 면접 메모, 회의록과 담당자·기한·완료 수동 기록을 제공합니다. 운영 결정과 인수인계는 템플릿/수동 기록으로 동작하고 외부 LLM 비용이 들지 않습니다.

선택 연장: QR 출석 스캔과 로컬 AI는 현재 완료 조건이 아닙니다. 실제 사용성·개인정보 경계·운영 비용을 확인한 뒤 별도 범위로 검토합니다. 유료 문자 API, 알림톡, AI 과금 전환도 기본 기능의 선행 조건이 아닙니다.

## 검증 상태를 나누는 기준

| 단계 | 증명하는 내용 | 다음 단계까지 자동으로 보장하지 않는 것 |
| --- | --- | --- |
| 단위/통합 테스트와 가상 데이터 | 규칙, 권한, 중복 처리, 충돌·복구 경로 | 실제 기기 또는 통신사 전송 |
| 로컬 빌드와 APK 생성 | 소스가 빌드되고 산출물이 생성됨 | APK 설치·앱 동작 |
| 전용 에뮬레이터 | 지정된 Android 화면/저장/서버 흐름 | SKT 회선과 Kakao 실기 공유 |
| Chrome 실제 브라우저 | 웹 반응형 UI와 브라우저 응답 흐름 | 외부 인터넷에서 운영 호스트 접근 |
| 실제 Android/SKT 기기 | 문자 앱/회선/공유와 OS 상호작용 | 상대의 수신·열람 여부 |
| 배포 호스트와 별도 기기 | 외부 접근 및 운영 서버 복구 | 수신자가 읽거나 입금한 사실 |

이번 구현의 개별 실행 결과는 STATUS.md를 읽습니다. 명령은 코드 상태가 바뀐 뒤 같은 조건에서 재실행할 수 있어야 하며, 문서의 예시 명령은 저장소 스크립트·Gradle wrapper를 기준으로 합니다.
