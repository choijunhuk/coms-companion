## 구현한 기능

Android는 홈·회원·행사·회비·연락의 다섯 탭과 설정을 제공한다. 회원 상세·다중 선택·수신 제외·탈퇴·CSV 검토, 단계형 행사 작성·상태 필터·수동 응답/현장 출석·일정 투표, 회비 부과/확인/면제/환불/정정 이력, 할 일과 연락 알림을 저장한다. 연락은 목적→대상→문구→검토와 초안/조건 보존, 계좌/개인 링크 치환, 실행 직전 대상 재검사를 사용한다.

문자는 한 명씩 ACTION_SENDTO로 작성 화면을 전달한다. SEND_SMS/READ_SMS/RECEIVE_SMS와 자동 발송은 없다. 앱 전달, 사용자 발송 표시, 실제 전송/회원 응답을 구별한다. 로컬 개발 빌드에는 Kakao 네이티브 키·패키지·서명 해시·개발 안내 URL을 설정하고 실기의 공식 공유 선택 화면을 확인했다. 공개 설정 예시와 CI에는 키가 없으며 일반 공유·복사를 제공한다. 기본 기능은 외부 LLM·유료 문자 API·알림톡을 호출하지 않는다.

온라인은 수동 응답 최초 이관, 운영자 제안 대기함, 공통 제출의 명시적 회원 연결, 변경 커서/충돌 검토/수동·연결 조건 동기화를 구현했다. 출석만 기록한 미응답 행은 서버 응답으로 만들지 않는다. 초대 취소는 파생 수정 권한까지 처리하며 탈퇴와 취소 등록을 같은 Room 트랜잭션에 저장한다. 서버 확인 전 링크를 복사하지 않는다.

회원 입금 요청은 주장이다. 운영자 확인→서버 예약→한 로컬 원장 효과→서버 확정으로 처리한다. 요청 금액과 실제 확인 금액, 내부 영수증을 구별하며 같은 작업 ID/원장 ID를 재사용한다. 과거 준비 영수증의 누락 필드는 최신 인증 스냅샷과 예약 6필드를 대조한다. 정정은 원본 삭제 대신 추가 원장이다.

Room v4에 명시적 1→2→3→4 migration을 제공한다. AES-GCM/PBKDF2 암호화 SAF 백업은 검증·미리보기 후 기존 자료의 별도 암호화 안전 파일부터 저장하고 원자적으로 복원한다. 서버 origin/owner는 보존하고 인증 토큰/자동 동기화는 해제한다. OS 기기 인증 잠금은 전경을 잃으면 민감 창을 제거하고 인증 취소를 차단한다. 편집 대상 로딩을 기다려 잠금 후 입력이 초기화되지 않도록 했다.

오래된 백업에 없는 서버 행사는 설정에 검토 대기 기록을 남기며 커서를 진행시키지 않는다. 승인 시 실제 행사/응답 스냅샷만 안정된 ID로 복구하고 회원·회비·출석을 만들지 않는다. 내용/버전이 바뀌면 다시 검토한다. 원래 변경 페이지를 다시 반영한 뒤 동기화를 재개한다.

운영 도구는 행사 지출/정산, 물품 대여·반납 이력, 지원자·면접 메모, 회의록·담당자·기한·결정 완료를 수동 저장한다. 현금 수입은 확인된 원장만 집계한다. 신규 의존성 없이 기존 Room·DataStore·WorkManager·플랫폼 기능을 사용했다. QR 스캔/선택 AI는 확장 범위다.

실제 문자·카카오톡 발송/수신, 장문 분할·이모지·듀얼 SIM 선택·과금, 실기의 앱 잠금 인증과 암호화 백업/복원, 공개 HTTPS 회원 응답은 이번 검사에 포함하지 않았다. 앞선 전용 에뮬레이터의 보호 기능 검증과 구별한다.

## 남은 외부 조건과 다음 세션

1. 로컬·전용 에뮬레이터·앞선 CI와 이번 실기 기본 업무/문자 작성/Kakao 공유 선택 화면을 확인했다. 실제 상대 선택/전송과 수신은 별도 조건이다. 실기의 보호·복원 및 장문/회선 동작도 남아 있다.
2. 사용자는 회원 응답용 공개 호스트를 지정하지 않았다. 자체 도메인 구매는 필수 조건이 아니지만 지속적인 HTTPS 호스트가 필요하다. 로컬 서버 비밀값은 준비했으며, 실제 배포에 맞는 `PUBLIC_BASE_URL`, 비공개 DB/백업, 휴대폰 온라인 설정과 별도 기기 접근/장애 복구를 확인해야 한다.
3. Kakao 앱·네이티브 키·패키지·현재 디버그 인증서 해시·개발 안내 공유 도메인 등록을 완료했다. 실제 값은 Git 제외 `apps/android/local.properties`에 있다. 회원 응답 호스트 준비 후 `kakao.shareUrl`과 제품 링크 도메인을 함께 변경하고 새 APK를 설치한다. 공개 예시는 빈 값이며 CI에는 실제 키가 없다.
4. SM-S928N/Android16/SKT 표시와 삼성 문자 앱의 한글 작성·복귀를 확인했다. 정확한 요금제·SIM 구성·장문·실전송은 미확인이다. 실제 상대에게 임의 전송하지 않았다.
5. CI 디버그 서명은 실행별로 다를 수 있다. 데이터가 있는 앱을 삭제해 업데이트 문제를 해결하지 말고 안정된 비공개 서명과 암호화 백업을 준비한다.

전용 QA AVD는 COMsCompanion_QA(5580)이며 테스트용 로컬 서버는 3100이다. 앱 잠금을 OS 인증 후 비활성화하고 전용 AVD에 설정했던 임시 테스트 PIN을 제거했으며 글자 배율/테마도 원상복구했다. 다른 기존 에뮬레이터/운영 DB를 이어 쓰지 않는다. 다음 세션은 실제 git HEAD/origin, 이 문서, API_COMPLETION과 COMPLETION_PLAN을 먼저 읽고 외부 조건부터 이어간다.
