## 완료한 구현

### apps/android

Kotlin/Compose/Material3 단일 모듈, Room 업무 데이터, DataStore 설정, 5개 탭과 빈 상태. 회원 검색/상태/그룹/기수 필터·등록/수정·수신 제외·CSV 미리보기와 중복/오류 구분. 행사·게시 전 수동 참석/출석, 청구와 납부/면제/환불/정정의 추가 원장 이력, 할 일. 템플릿 치환·누락 검사·개인별 미리보기·초안·연락 스냅샷. 탈퇴·수신 제외·중복 번호·납부 완료 대상 재검사.

문자는 ACTION_SENDTO/smsto 한 명씩. SEND_SMS/READ_SMS/RECEIVE_SMS 없음. 앱 전달·사용자 발송 확인·실패 구분과 중복 실행 방지. 공식 Kakao SDK와 설정 예시, 일반 공유/복사 대안, SDK 실패와 명시적 대안 선택, 공통 공유 개인정보 검사. WorkManager 운영자 알림/권한 거부 상태. 라이트/다크/시스템 테마.

온라인 연결은 수동 행사 게시·공통/개인 링크 발급·읽기 전용 응답/입금 주장 스냅샷과 마지막 가져오기 시각. 작업 ID/요청 본문을 먼저 저장해 불확실 실패 재시도. 확정된 거절은 수정 가능. 서버 확인 전 링크 표시 없음. 온라인 상태 이후 서버 주소 교체 차단(토큰 교체 가능).

### apps/web / apps/server

React/TS/Vite 모바일 응답 웹과 Fastify/TS/SQLite 단일 서버. 상세→입력→검토→명시적 저장→완료/수정. 참석·안내 확인·일정 투표·개인 입금 확인 요청. 공통 제출은 미확인과 자기 응답 수정 토큰, 이름/번호 자동 연결 없음.

토큰 해시·행사/회원/동작/만료/취소 제한, URL fragment와 인증 헤더, 캐시/요청 로그 제외. 관리자 라우트별 인증, 입력·정원·마감·행사/응답 버전 검사, 명시적 회원 연결과 입금 검토 API. 암호화 작업 영수증과 동일 요청 재시도, SQLite 재시작 유지. 마감 후 신규 제출 금지/기존 저장 결과 회수. 불확실 저장은 원본 요청 보존과 수정 잠금, 삭제 후보의 기존 선택 유지.

회원 입금 주장을 앱 납부 원장에 자동 반영하지 않는다. Android에서는 읽기 전용이며 전체 검토 UI/자동 동기화는 남았다.

추가 복구: 불확실 웹 요청은 작업 ID와 본문을 링크별 세션에 먼저 저장해 hard reload 후 회수한다. 408/429와 이전 미확인 작업의 후속 오류에서도 작업을 잃지 않는다. 행사 취소가 Room→게시→웹까지 전달되고 기존 응답은 보존된다. 원장 한 건 금액 상한은 10억 원이다. 주요 색 대비6쌍 계산 결과 모두 4.5:1 이상(최저5.47:1).
